# Lab 06: Server Security Hardening (Ubuntu)

##  Project Overview
This project demonstrates how to secure a Linux server using industry best practices.

##  Key Security Implementations
- SSH Hardening
- Firewall Configuration (UFW)
- Fail2Ban Intrusion Prevention
- System Auditing (auditd)
- Security Scanning (Lynis)

##  Tools Used
- Ubuntu Server
- Vagrant + VirtualBox
- UFW
- Fail2Ban
- auditd
- Lynis
